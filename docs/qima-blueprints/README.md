# QIMA Blueprint Documents

This directory contains the ordered QIMA v1.0 blueprint stack. File names use a stable numeric prefix so the implementation sequence is clear and easy to reference.

## Baseline Documents

| Order | Document | Purpose |
| --- | --- | --- |
| 01 | [Master Platform Blueprint](./01-master-platform-blueprint.md) | Establishes the QIMA platform foundation, identity, and multi-unit architecture. |
| 02 | [Capability Gap Matrix](./02-capability-gap-matrix.md) | Maps required platform capabilities, gaps, priorities, and domains. |
| 03 | [Capability → Data Model → Module Contract](./03-capability-data-model-module-contract.md) | Connects capabilities to domain boundaries, entities, modules, services, UI, and API responsibilities. |
| 04 | [Module Composition & User Journey Contract](./04-module-composition-user-journey-contract.md) | Defines user roles, journeys, screens, actions, modules, and data flows. |
| 05 | [Technical Architecture & Implementation Blueprint](./05-technical-architecture-implementation-blueprint.md) | Describes the implementable architecture for apps, services, domain core, data access, and deployment. |
| 06 | [Database Schema, API Contract & Domain Specification](./06-database-schema-api-contract-domain-specification.md) | Defines domain, database, API, authorization, reporting, and integration contracts. |
| 07 | [UX/UI Design System & Screen Specification](./07-ux-ui-design-system-screen-specification.md) | Establishes UX principles, navigation, layouts, components, screens, and accessibility expectations. |
| 08 | [Implementation Contract, Repository & Module Structure](./08-implementation-contract-repository-module-structure.md) | Defines repository structure, module boundaries, coding rules, environment contracts, and implementation sequence. |
| 09 | [Testing, QA & Delivery Blueprint](./09-testing-qa-delivery-blueprint.md) | Specifies quality gates, testing strategy, release validation, and delivery expectations. |
| 10 | [Master Traceability Matrix + Implementation Execution Plan](./10-master-traceability-matrix-implementation-execution-plan.md) | Acts as the master control document for traceability, dependencies, acceptance criteria, and delivery order. |

## Archive

The [`archive/`](./archive) folder keeps early drafting notes and naming-transition material that should not be treated as the current baseline.
