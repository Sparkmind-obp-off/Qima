# QIMA — Demo User Journey

## Prinsip
Demo harus terasa seperti **cerita pekerjaan sehari-hari**, bukan tour menu.

## Journey utama
### 0. Context
"Bayangkan hari ini ada beberapa santri baru, guru perlu melihat jadwal, dan pengelola ingin tahu kondisi kelas."

### 1. Masuk ke QIMA
Tampilkan landing/entry screen.

Pesan:
> "Kelola aktivitas Rumah Qur'an dengan lebih terstruktur."

CTA:
- Mulai Demo
- Lihat Cara Kerja

### 2. Pilih konteks
Prototype menampilkan:
- Pengelola
- Admin
- Guru
- Orang Tua/Santri

Untuk demo pertama, pilih **Pengelola/Admin**.

### 3. Dashboard
Tampilkan ringkasan:
- Santri aktif
- Kelas
- Guru
- Kehadiran
- Agenda hari ini
- Hal yang membutuhkan perhatian

Jangan terlalu banyak angka.

### 4. Santri
Klik satu santri → profil → kelas → kehadiran → progres.

Tujuannya menunjukkan bahwa informasi tidak tersebar.

### 5. Kelas
Pilih kelas → daftar santri → jadwal → kehadiran.

### 6. Aktivitas
Tampilkan agenda/kegiatan.

### 7. Insight
Tampilkan ringkasan sederhana:
> "Ada 3 santri yang perlu diperhatikan minggu ini."

Ini hanya simulasi UI.

### 8. Tutup demo
Tanya:
> "Kalau alur seperti ini diterapkan di lembaga Bapak/Ibu, bagian mana yang paling membantu?"

Lalu:
> "Bagian mana yang justru tidak sesuai dengan cara kerja sekarang?"
