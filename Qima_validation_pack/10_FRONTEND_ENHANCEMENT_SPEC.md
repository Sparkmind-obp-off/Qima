# QIMA — Frontend Enhancement Spec v1.0

## Target
Membuat prototype mudah dipahami tanpa presenter harus menjelaskan semuanya.

## P0 — Wajib
### 1. Demo Entry
- Judul QIMA
- Label "Prototype Demo"
- Penjelasan 1 kalimat
- CTA "Mulai Demo"

### 2. Role Selector
- Pengelola
- Admin
- Guru
- Orang Tua/Santri

### 3. Guided Demo
- Progress indicator: 1/5, 2/5, dst.
- Next/Back
- Skip tour
- Tooltip singkat

### 4. Realistic Seed Data
Gunakan data simulasi yang terasa masuk akal:
- nama santri;
- kelas;
- guru;
- jadwal;
- kehadiran;
- progres.

### 5. Scenario Switcher
Contoh:
- Santri Baru
- Kehadiran
- Progres
- Agenda

### 6. Feedback CTA
Setiap demo selesai:
> "Apa yang perlu diubah?"

CTA:
- Sangat relevan
- Cukup relevan
- Belum sesuai
- Ada kebutuhan lain

## P1 — Bagus jika sempat
- Demo reset
- "You are here" breadcrumb
- Empty state
- Highlight perubahan
- Modal "Mengapa ini penting?"

## P2 — Jangan dulu
- Backend
- Auth nyata
- Database produksi
- Payment
- Notification infrastructure
- Complex permissions
- Advanced analytics

## Prinsip UI
**Kurangi menu, perbanyak konteks.**
