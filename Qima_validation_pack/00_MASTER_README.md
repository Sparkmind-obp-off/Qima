# QIMA — Demo & Validation Pack v1.0

## Tujuan
Paket ini adalah panduan kerja untuk mengubah QIMA dari sekadar mockup menjadi **prototype yang mudah dipresentasikan dan divalidasi** kepada pengelola Rumah Qur'an/yayasan.

**Fokus fase ini: FRONT-END / MOCKUP INTERAKTIF.**
Tidak perlu backend, database, autentikasi nyata, payment, atau integrasi produksi.

## Prinsip
1. Jangan mengklaim sistem sudah menyelesaikan semua masalah.
2. Gunakan demo untuk menemukan masalah nyata.
3. Tampilkan alur kerja, bukan daftar fitur.
4. Setiap pertemuan menghasilkan catatan kebutuhan.
5. Backend baru dibangun setelah kebutuhan utama tervalidasi.
