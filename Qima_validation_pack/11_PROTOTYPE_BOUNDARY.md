# QIMA — Prototype Boundary

## Termasuk
- UI responsive
- Navigasi
- Mock data
- Interaksi klik
- Guided tour
- Role switching
- Scenario switching
- Simulasi tambah/edit
- Simulasi filter/search
- Simulasi dashboard
- Feedback flow

## Belum termasuk
- Database production
- Auth production
- Multi-tenant backend
- Real-time sync
- Payment
- Email/WhatsApp gateway
- Audit log production
- Backup
- Security hardening
- Production analytics

## Kriteria selesai fase prototype
Prototype dianggap siap divalidasi bila:
1. orang baru memahami konsep dalam ≤ 2 menit;
2. presenter bisa demo dalam ≤ 5 menit;
3. minimal 3 skenario dapat dimainkan;
4. minimal 2 role dapat dibandingkan;
5. pengguna bisa memberi feedback tanpa penjelasan panjang;
6. tidak ada klaim bahwa prototype sudah production-ready.
